# Rohit Parne - Cinematic Portfolio

Interactive machine learning portfolio built with HTML, CSS, JavaScript, and a Canvas 2D career graph. No build step or backend is required.

## Open locally

Open `index.html` in a browser. Sound is muted by default and can be enabled with the music button. Animation can be paused, and reduced-motion preferences are respected.

## Publish with GitHub Pages

1. Open this repository's Settings > Pages.
2. Under Build and deployment, choose Deploy from a branch.
3. Select `main` and `/(root)`, then Save.
4. Once deployment finishes, visit https://sairohitparn.github.io/Portfolio/.

## Files

- `index.html`: portfolio structure and contact links.
- `interface.css`: cinematic layout and responsive styles.
- `interface.js`: animated graph, career dossiers, and sound controls.
- `portfolio-projects.js`: Chat3GPP and ATS Resume Scorer content.
- `portfolio-projects.css`: project presentation styles.
- `resume.docx`: downloadable resume.

Project repositories and demo links can be added when available. Google Fonts is the only external styling dependency; system font fallbacks are provided.
